# デジタル絵譜 v1.0.0

特別支援学校の合奏練習向けWebアプリです。

## 主な機能
- MP3/M4A/WAVなどの音声、MP4などの動画を端末から追加
- 音声ファイルはテンポ(BPM)を自動解析（簡易解析）
- 4回タップによるテンポ補正
- 小中学校で扱う代表的な楽器を内蔵、複数選択可能
- 独自楽器と画像を追加して保存
- 擬音と拍数によるリズム作成、マイリズム保存
- 音程文字の表示（例: ド / C4）
- 全パート絵譜 / 1パート拡大表示
- 曲終了時の褒め演出
- IndexedDBによる曲・楽器・リズム・プロジェクト自動保存
- JSONバックアップ書き出し / 読み込み（端末間の移行用）
- Service Workerによるオフライン起動（HTTPS配信後、一度オンラインで開いた後）

## GitHub Pages
このフォルダーのファイルをリポジトリ直下にアップロードし、GitHub Pagesを有効にしてください。
Service Workerは `https://` または localhost で動作します。`file://` でHTMLを直接開いた場合、オフラインキャッシュは有効になりません。

## 対応想定
- iPad/iPhone: Safari / Chrome
- Mac: Safari / Chrome
- Windows: Edge / Chrome

## 注意
- iPhoneのブラウザーでは Fullscreen API に制限があるため、アプリ内の没入表示を併用します。
- 自動テンポ解析は一定テンポの音源で特に有効です。生演奏やテンポ変化の多い曲は4回タップ補正を利用してください。
- 動画は再生できますが、ブラウザーによって音声デコードの制限があるためテンポ自動解析の対象外とし、4回タップ補正を使います。
- ブラウザーのサイトデータを削除すると保存内容が消える可能性があります。重要な設定はバックアップしてください。
