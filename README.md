# デジタル絵譜

特別支援学校などでの合奏練習に向けた、絵譜と音源のWebアプリです。

[デジタル絵譜を開く](https://kamekamelab.github.io/visual-ensemble-score/)

## 主な機能

- 音声・動画の読み込みとテンポ、1拍目の調整
- 楽器パート、絵、擬音、リズムの編集
- MusicXMLとMIDIからの楽譜読み込み
- 全パート表示、1パート表示、演奏用表示
- 譜面のタイミングで鳴る練習用パート音、パートごとの音量調整と一括消音
- メトロノームの音量調整
- 現在位置からの練習区間設定、通常再生前のカウント、演奏中の画面スリープ防止
- `.enscore` 教材ファイルの書き出し・読み込み
- 複数端末への絵譜共有、カウント数を選べる同期演奏
- 端末内への自動保存とオフライン起動

## 教材データ

編集した教材は、使用中のブラウザー内に保存されます。大切な教材は「保存・読み込み」から `.enscore` ファイルに書き出し、別の場所に保管してください。

## 同期機能

端末間同期にはインターネット接続と外部のPeerJS通信サービスを使います。先生が許可した端末には、教材名、絵譜、楽器や演奏の設定、設定した画像が送られます。音源ファイルは送られません。
